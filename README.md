# Activity Reminder App

## How to Run the Project

Project Folder: **ActivityApp-master**

1. Install **Android Studio** (if not already installed).

2. Download or open the project folder.

3. Open **Android Studio**.

4. Click **Open** and select the project folder.

5. Wait for **Gradle Sync** to complete.

6. Choose a device:

   * Android Emulator, or
   * Physical Android phone (recommended for sensors)

7. Click the green **Run ▶** button.


## Notes

* A physical Android phone is recommended because the app uses **accelerometer and gyroscope sensors**.
* If the app does not run, check Gradle sync and device connection.
